# ระบบบันทึกยอดขายร้านอาหาร (เวอร์ชันเริ่มต้น)

เว็บแอปมือถือสำหรับบันทึกยอดขายแยกตามเมนูและจำนวน รองรับหลายคนจากหลายเครื่องผ่านฐานข้อมูลเดียวกัน

## สิ่งที่ทำได้
- สมัครบัญชี/เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- เพิ่มเมนูและราคา
- บันทึกยอดขายเป็นรายการ โดยเลือกจำนวนแต่ละเมนูและช่องทางรับเงิน
- ดูยอดขายรายวัน แยกเงินสด/เงินโอน
- ดูรายการย้อนหลังตามวันที่
- ส่งออกรายการเป็น CSV เพื่อเปิดใน Excel

## สิ่งที่ต้องรู้ก่อนใช้งาน
- นี่คือ source package ที่ต้องนำไปเผยแพร่บนเว็บโฮสติ้งและเชื่อม Supabase ก่อน จึงจะใช้งานร่วมกันหลายเครื่องได้
- ข้อมูลออนไลน์จะใช้ได้เมื่อมือถือเชื่อมอินเทอร์เน็ต
- อย่าใส่ Supabase `service_role` key ในหน้าเว็บเด็ดขาด ใช้เฉพาะ publishable/anon key
- เฉพาะบัญชีที่เจ้าของร้านอนุญาต (ตาราง staff) เท่านั้นที่อ่านหรือบันทึกข้อมูลได้ แม้คนอื่นสมัครบัญชีได้ก็มองไม่เห็นข้อมูลร้าน
- เคลียร์บิลได้ทีละบิล (ลบถาวร ไม่เหลือประวัติ) แต่ยังไม่มีการแก้ไขบิลและยังไม่คำนวณกำไรสุทธิจากต้นทุนวัตถุดิบ

## ขั้นตอนตั้งค่าครั้งแรก

### 1. สร้างฐานข้อมูล Supabase
1. เข้า https://supabase.com/ แล้วสร้าง project ใหม่
2. ตั้งชื่อเช่น `restaurant-sales` และตั้งรหัสฐานข้อมูลที่ปลอดภัย
3. รอให้ project พร้อม
4. เปิดเมนู SQL Editor แล้วเปิดไฟล์ `schema.sql` คัดลอกทั้งหมดไปวางและกด Run
5. ไปที่ Project Settings > API (หรือ Connect) แล้วคัดลอก Project URL และ publishable key/anon key

### 2. เผยแพร่เว็บแอป
นำไฟล์ `index.html` และ `manifest.webmanifest` ไปวางใน static hosting ที่รองรับ HTTPS เช่น Netlify, Cloudflare Pages หรือ GitHub Pages
- ไฟล์ `index.html` เป็นตัวแอปหลัก
- ไม่จำเป็นต้องเผยแพร่ `schema.sql` ไปพร้อมหน้าเว็บ
- เปิด URL เว็บแอปผ่านมือถือ

### 3. เชื่อมฐานข้อมูล
ในหน้าแอป กรอก Supabase Project URL และ publishable/anon key แล้วกด “บันทึกการตั้งค่าในเครื่องนี้”

### 4. สร้างบัญชีพนักงาน
1. สมัครบัญชีด้วยอีเมลและรหัสผ่านจากหน้าแอป
2. ถ้าตั้งค่า Supabase ให้ยืนยันอีเมล ต้องเปิดอีเมลยืนยันก่อนเข้าสู่ระบบ
3. ให้พนักงานแต่ละคนใช้บัญชีของตัวเอง ไม่ควรแชร์รหัสผ่านกัน
4. ถ้าไม่ต้องการให้คนทั่วไปสมัครบัญชีได้ ให้ปิด public signups ใน Supabase Auth หลังสร้างบัญชีพนักงานที่ต้องใช้ครบแล้ว

### 5. เพิ่มเมนูและทดลอง
1. เข้าสู่ระบบ
2. เพิ่มเมนูและราคาจริงของร้าน เช่น ข้าวต้มหมู, ข้าวแห้งหมู, ก๋วยเตี๋ยวหมู
3. ทดลองบันทึกยอดขายจำลอง 1-2 รายการ
4. ตรวจว่ายอดขายและช่องทางรับเงินถูกต้อง
5. กดส่งออก CSV เพื่อทดสอบสำรองข้อมูล

### 6. เพิ่มไอคอนบนหน้าจอมือถือ
- Android Chrome: เปิด URL > เมนู ⋮ > “เพิ่มลงในหน้าจอหลัก” หรือ “ติดตั้งแอป” (ชื่ออาจต่างกัน)
- iPhone Safari: Share > Add to Home Screen

## ความปลอดภัยและการสำรอง
- ใช้รหัสผ่านที่ไม่ซ้ำกับบริการอื่น
- จำกัดบัญชีเฉพาะคนในร้าน
- ส่งออก CSV เป็นประจำและเก็บไว้นอกมือถือ
- ก่อนใช้งานจริง แนะนำให้ทดสอบกับข้อมูลจำลองก่อน

## v2: สิ่งที่เปลี่ยน
- บันทึกบิลผ่านฟังก์ชัน `create_sale` ใน transaction เดียว ราคาอ่านจากเมนูฝั่งเซิร์ฟเวอร์ และกันบิลซ้ำเมื่อกดซ้ำ/เน็ตหลุด
- เคลียร์บิลทีละบิลด้วยปุ่ม “เคลียร์บิล” (บิลหายจากรายการและ CSV ถาวร กู้คืนไม่ได้) ต้องรัน `schema.sql` ใหม่หนึ่งครั้ง
- ระบบพนักงาน: **คนแรกที่เข้าสู่ระบบกด “ตั้งบัญชีนี้เป็นเจ้าของร้าน”** หลังจากนั้นเจ้าของเพิ่มพนักงานด้วยอีเมล (พนักงานต้องสมัครบัญชีก่อน)
- วันที่แสดงเป็น วัน เดือน ปี (พ.ศ.) และ CSV ใช้รูปแบบ วว/ดด/ปปปป (พ.ศ.)
- สรุปยอดแยกตามเมนู ดูได้ 1 วัน / 7 วัน / ทั้งเดือน และ CSV ส่งออกตามช่วงที่เลือก
- เปลี่ยนชื่อเมนูได้ (บิลเก่ายังแสดงชื่อเดิม ณ ตอนขาย)
- ถ้ารัน schema v1 ไปแล้ว ให้รัน `schema.sql` ใหม่ทับได้เลย (ข้อมูลเดิมอยู่ครบ) แล้วเข้าแอปและกดตั้งเป็นเจ้าของร้านก่อน
- ใส่ URL และ key ของ Supabase ไว้ที่บรรทัดบนสุดของสคริปต์ใน `index.html` (`SUPABASE_URL`, `SUPABASE_KEY`) เพื่อไม่ต้องตั้งค่าทุกเครื่อง
